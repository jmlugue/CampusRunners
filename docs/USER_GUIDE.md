# USER_GUIDE.md

## CampusRunners User Guide

## Student Requester

1. Register using full name, school email, student number, and password.
2. Login.
3. Tap Post Errand.
4. Fill out the errand title, description, category, pickup location, drop-off location, deadline, and optional reward.
5. Submit the errand.
6. Wait for helpers to apply.
7. View applicants.
8. Select a helper.
9. Message the selected helper if needed.
10. Wait for the helper to mark the errand as completed.
11. Confirm completion.
12. Rate the helper.

## Student Helper

1. Login.
2. Tap Browse Errands.
3. View available errands.
4. Apply to an errand.
5. Wait to be selected.
6. Accept the assigned errand.
7. Message the requester if needed.
8. Mark the errand as In Progress.
9. Mark the errand as Completed by Helper.

## Admin

1. Login as admin.
2. View dashboard counts.
3. Monitor users, errands, reports, ratings, and flagged errands.
4. Restrict or deactivate users if needed.
5. Remove inappropriate errands if needed.
6. Resolve reports.
