# PRESENTATION_FLOW.md

## Suggested Presentation Flow

1. Title Page
   - IT140P-MP-CampusRunners
   - CampusRunners
   - Group members

2. Problem Background
   - Students often need small errands done during busy school days.
   - Current errand requests are usually made through chat.
   - Chat-based requests can be unorganized, unsafe, and hard to track.

3. Proposed Solution
   - CampusRunners is a school-only micro-errand request app for MCL students.
   - It allows verified students to post errands, apply as helpers, select helpers, track status, message, confirm completion, rate, and report issues.

4. Target Users
   - Student Requester
   - Student Helper
   - Admin

5. REST Architecture
   - Android App
   - PHP REST API
   - MySQL Database

6. Database Overview
   - users
   - errands
   - errand_applications
   - messages
   - ratings
   - reports
   - moderation_logs

7. Main Features
   - Registration and login
   - Post errand
   - Browse errands
   - Apply as helper
   - Select helper
   - Status tracking
   - Messaging
   - Rating
   - Reporting
   - Admin monitoring

8. Safety and Privacy
   - School email and student number verification fields
   - No public display of student numbers or school emails
   - Banned errand moderation
   - Report system
   - Admin restriction controls

9. Demo Flow
   - Login as requester
   - Post bluebook errand
   - Login as helper
   - Apply to errand
   - Login as requester
   - Select helper
   - Login as helper
   - Accept and update status
   - Message requester
   - Mark completed
   - Login as requester
   - Confirm completion and rate
   - Login as admin
   - View dashboard and reports

10. Evaluation Results
   - Show Google Form link
   - Show number of respondents
   - Show average results
   - Summarize user feedback

11. Conclusion
   - CampusRunners provides a structured, safer, and more organized way for students to request and complete small school-related errands.

12. Future Improvements
   - Real-time chat
   - Push notifications
   - Email OTP verification
   - Proof of delivery image upload
   - AI-based moderation
   - Payment gateway integration if approved by school policy
